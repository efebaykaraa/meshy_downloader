# Meshy Downloader

WXT + Svelte extension.

Detects and downloads models from meshy.ai for free.

_TODO: Compressed release file will be added until May 26th._

## Browser Support

| Browser | Status |
|---|---|
| Chrome | ✅ Works |
| Firefox | ❌ Does not work |
| Safari | ⚪ Not tested |


## Install

```bash
pnpm install
pnpm dev
```

For a production build:

```bash
pnpm build
```

Load `.output/chrome-mv3` as an unpacked extension.
