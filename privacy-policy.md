# Meshy Downloader Privacy Policy

_Last updated: May 22, 2026_

Meshy Downloader is an independent browser extension that works on Meshy pages to help users detect available model download actions and start downloads with user consent.

Meshy Downloader is not affiliated with, endorsed by, or officially connected to Meshy.

## Data We Collect

Meshy Downloader does not collect personal information such as names, email addresses, passwords, payment information, or account credentials.

The extension may process limited technical data locally in the browser, including:

- The active tab URL, only to check whether the user is on a Meshy page
- Temporary model-related page state needed to show the download prompt
- User preferences, such as “Never show again”
- Temporary download-related state needed to complete a user-requested download

## How We Use Data

The extension uses this data only to provide its main functionality:

- Detecting whether the user is on a Meshy page
- Showing a download prompt when a compatible model download is detected
- Remembering user preferences
- Starting a download only when the user chooses to do so

## Local Storage

Meshy Downloader may store user preferences and temporary extension state using the browser’s local extension storage.

This data remains on the user’s device unless the browser itself syncs extension data through the user’s browser account settings.

## Data Sharing

Meshy Downloader does not sell, rent, or share user data with third parties.

The extension does not send collected data to external analytics services, advertising networks, or tracking platforms.

## Remote Code

Meshy Helper does not load or execute remote JavaScript or remote WebAssembly as extension code.

All extension code is packaged with the extension.

## Third-Party Websites

Meshy Downloader works on Meshy pages, but it is not responsible for Meshy’s own website, services, privacy practices, or data processing.

Users should review Meshy’s own privacy policy for information about how Meshy handles data on its platform.
